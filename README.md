# Proyecto: GOLAZO ⚽🎬

Plataforma oficial de eventos deportivos y entretenimiento multimedia con sistema de acceso y autenticación segura de usuarios CineMax/GOLAZO (Conflicto resuelto exitosamente).

## Tecnologías utilizadas
- HTML5
- CSS3
- JavaScript

## Estructura del proyecto
- `index.html`: Portal principal con cartelera de partidos y eventos.
- `login.html`: Sistema de acceso para usuarios registrados.
- `styles.css`: Hojas de estilo modernas y responsivas.
